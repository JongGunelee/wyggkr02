# 📂 End-of-Month Repository-

이 저장소는 **매월 마감 자료 공유용 저장소**입니다.  
2014년부터 현재까지의 연도별 폴더와 관련 문서를 정리하여 관리합니다.  
현재는 최신 연도부터 역순으로 정리되어 있으며, 기존 자료도 정기적으로 업로드 예정입니다.  
묶음으로 PDF로 업로드되지만 요청시 개별 파일을 압축(검토X)해서 업로드 예정 입니다.

## 📑 사용 방법
1. 위 목록에서 원하는 연도를 클릭하면 해당 연도 폴더로 이동합니다.  
2. 각 폴더 안에서 월별 PDF나 ZIP 파일을 확인할 수 있습니다.  
3. 새로운 자료가 추가되면 커밋 메시지를 통해 변경 내역을 확인하세요.
