# Task 127 — 자동 분할 맞춤 및 잘라내기/삭제 취소

## 사용법

- 도구 > 모든 창 크기 맞추기: 새 설정의 기본값은 체크됨. 체크 상태는 `main.view.auto_equalize`로 저장된다.
- 체크됨: 수동 분할선 드래그는 허용하며, 명시적 새로 고침·전체 창 크기 변경·레이아웃 변경 시 같은 크기로 재분할한다. 분할선 드래그 도중이나 백그라운드 폴더 감시 갱신에는 자동 맞춤하지 않는다.
- 체크 해제: 기존 비율/고정 크기 설정대로 수동 분할을 유지한다. 창 > 같은 비율로 분할하기는 체크와 무관하게 한 번 실행된다.
- Task128 후속 변경(사용자 승인): 자동 맞춤 ON은 분할 잠금 OFF, 분할 잠금 ON은 자동 맞춤 OFF다. 자동 맞춤을 해제하면 분할 잠금도 해제해 두 체크 OFF인 수동 모드가 된다. 마지막 수동 크기를 재시작 때 복원하며 위치·경로·시계 잠금과 기존 분할 잠금 저장값은 보존한다. 이전 설정에서 둘 다 ON이면 시작 시 분할 잠금 스냅샷을 우선하고 자동 맞춤을 해제한다. 분할 잠금 ON을 사용자가 다시 선택하면 그때 캡처한 고정 크기 복원이 우선한다.
- 창 위치·크기/경로/분할 잠금의 저장 스냅샷은 별도 기능이다. 자동 맞춤은 잠금 스냅샷을 갱신하지 않는다.
- Delete는 휴지통 사용이 가능한 대상에서 복원이 가능하다. Shift+Delete, 휴지통이 없는 대상, 비워진 휴지통은 복원 불가다. 파일 작업이 완료된 뒤 Ctrl+Z를 사용한다.

## 실제 코드 원인과 수정

1. 기존 같은 비율 분할은 분할선 폭까지 포함해 나눠 마지막 창이 더 작았다. 분할선 폭을 제외하고 정수 나머지를 분배해 차이를 1픽셀 이내로 제한한다.
2. Splitter/ExplorerView는 DeferWindowPos의 새 HDWP를 버렸다. 공통 배치로 핸들 반환값을 연결하고 실패 시 전체 대상에 SetWindowPos를 적용한다. 변하지 않은 실제 창 사각형은 생략하고 활성 창을 바꾸지 않는다.
3. 일반 붙여넣기는 UI에서 파일별 셸 이름 조회를 했다. CF_HDROP 경로를 우선 사용하고 STGMEDIUM은 ReleaseStgMedium으로 한 번 해제한다. 가상 항목은 기존 셸 경로를 유지한다.
4. 이동 후 취소 기록의 파일시스템 조회가 UI 타이머에 있었다. worker에서 완료 기록을 생성한다. 메뉴의 취소 가능 검사도 worker 잠금을 기다리지 않는다.
5. 휴지통 $I 파서는 버전을 읽지 않고 파일 크기로 오프셋을 추정했고, DWORD에 7/8바이트를 썼다. 버전 1/2·64비트 크기·UTF-16 길이를 경계 검사한다. 다른 드라이브 기록 누적과 같은 드라이브 반복 열거를 제거하고 실제 휴지통 검색은 worker에서 수행한다.
6. 복원 대상을 못 찾아도 취소 기록을 지우던 동작을 제거했다. 복원 작업의 성공이 확인된 경우에만 마지막 기록을 소모한다. 실패·취소는 재시도 기록을 보존한다.

## 검증 상태

2026-10-13 확인 범위의 수정·배포 완료. 정적 회귀 스크립트 45/45 및 신규 검사 22개 통과. x64 단위 실행 77,254개 통과. x86 단위 시험 실행은 `Access is denied`로 차단되어 합격으로 기록하지 않는다. 이전 빌드·배포 후 삭제 복원 실기에서 추가 결함을 발견해 완료 판정을 철회하고 수정·전체 재빌드·재배포·GUI 재시험을 수행했다.

삭제 복원 경로를 내부 `xpr::String`으로 구성하면 중간 NUL이 보존되지 않아 다중 경로가 합쳐지고 `SHFileOperation`이 오류 124를 반환했다. 공통 `OperationPathPairs`의 표준 문자열로 구분 NUL과 마지막 NUL을 보존한다. 수정한 공유 경로 구성과 실제 `BBInfoFile`을 사용하는 native 시험에서 승인된 합성 항목 3개 복원이 성공했으며 원본 SHA-256도 일치했다. 이 시험은 콘솔 엔진 시험으로 GUI Ctrl+Z 최종 재시험을 대체하지 않는다. 복원 후 `$I` 메타데이터 잔재도 관측됐으며 데이터 복원 성공과 휴지통 정리 완료를 혼동하지 않는다.

최신 수정의 전체 x64/x32 재빌드와 세 패키지 동기화를 완료했다. x64 GUI에서 승인된 파일 2개와 폴더 1개를 Delete 후 첫 Ctrl+Z로 복원했고 해시·세 원본 패널 자동 갱신을 확인했다. x64 ON/OFF/F5/최대화와 x32 기본 ON/수동 분할/F5도 확인했다. 최종 manifest는 `__BUILD_TEMP_BACKUP__/unified_deploy_20261013_035047_082/deployment_manifest.json`, 상세 실패·정리·한계는 가이드 Task 127 및 `task127_results_20261012/RESULTS.md`를 따른다. 진행 중 Ctrl+Z 예약, x32 GUI 삭제 복원, 부분 복원/충돌 모든 조합 및 장시간 응답 없음의 완전 해결은 보장하지 않는다.
