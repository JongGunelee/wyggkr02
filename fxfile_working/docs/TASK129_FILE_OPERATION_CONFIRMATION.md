# Task129 — 파일 작업 전에 확인

개별 또는 여러 파일·폴더를 선택해 복사·이동·삭제·잘라내기·붙여넣기를 실행할 때, 파일 작업 확인창에서 **확인**을 눌러야 요청을 실행한다. 드래그 복사도 포함하며 이전 설정의 외부 파일 작업 옵션과 관계없이 적용한다. 확인 생략 또는 ‘다시 묻지 않음’ 옵션은 제공하지 않는다.

확인창은 작업 종류, 선택한 항목 수, 모든 대상의 전체 경로, 도착지를 보여 준다. 폴더 선택은 그 하위 내용까지 포함하며 항목 수는 선택한 최상위 항목 수다. 목록은 읽기 전용이고 가로·세로 스크롤 및 창 크기 조절을 지원한다. 기본 버튼은 **취소**다. Enter는 항상 취소하며 Esc, 취소 또는 창 닫기도 이 요청을 실행하지 않는다. **확인 버튼을 눌러 승인**해야 실행한다. 기존 이름 충돌의 덮어쓰기 확인은 기존 엔진 절차를 따른다.

확인창, 대상 변경으로 실행을 거부하는 안내창과 FxFile 오류 보고창은 **맑은 고딕 12pt**를 사용한다. 확인창은 실제 글꼴 크기로 안내·목록·버튼을 배치하고 모니터 작업 영역 안에 표시한다. 대상 목록이 길면 스크롤하거나 창을 늘려 전체 경로를 확인할 수 있다.

| 작업 | 확인할 내용 |
|---|---|
| 왼쪽 드래그 | 복사/이동과 실제 놓은 폴더. Shift 드래그는 이동 |
| 오른쪽 드래그 | 먼저 복사/이동/바로가기 중 하나를 고른 뒤 해당 작업의 대상·도착지 확인 |
| 잘라내기 | 출발 대상 확인. 이 시점에는 파일을 옮기지 않고 클립보드에 이동 대기 등록 |
| 잘라낸 항목 붙여넣기 | 출발 대상과 도착지를 다시 확인. 성공한 항목은 출발지에서 사라짐 |
| 복사한 항목 붙여넣기 | 대상과 도착지 확인. 동일 폴더의 복제 요청은 추가 복사본 가능성을 표시 |
| 삭제 | 휴지통 삭제와 Shift 영구 삭제를 구별해 확인 |
| 압축 파일의 붙여넣기 | 추출 또는 압축 추가의 원본과 도착 압축 경로 확인 |

잘라내기/붙여넣기를 취소하면 FxFile은 그 요청 때문에 클립보드를 비우지 않는다. 내부 이동이 실패·취소·부분 완료되면 잘라내기 정보를 보존하며, 같은 잘라내기 내용의 이동이 진행 중인 동안 중복 이동 요청을 거부한다. 전체 항목의 이동 성공이 확인되고 클립보드 내용이 이후 바뀌지 않았을 때만 완료한 잘라내기 정보를 비운다. 확인창이 열린 동안 클립보드가 바뀌면 기존 이동 요청은 실행하지 않는다.

잘라내기 확인을 취소하면 선택 항목의 흐린 표시도 바꾸지 않는다. 승인해 클립보드에 등록한 뒤에만 해당 항목을 이동 대기로 표시한다.

파일 경로와 선택 대상은 확인 전에 고정한다. 확인창의 메시지 루프 중 파일 목록이 갱신되어도 새 선택 항목으로 바꾸어 실행하지 않는다. 일반 파일이 `FileContents`/텍스트 형식도 제공하더라도 파일 복사·이동 경로를 우선하여 확인을 우회한 내용 가져오기 및 이동 대신 복사를 방지한다. 파일 내용만 제공하는 외부 항목은 대상 이름·도착지를 확인하고, 취소하면 다른 형식으로 넘어가 파일을 만들지 않는다.

FxFile 밖의 프로그램으로 드래그할 때도 전달 전에 확인한다. 그 경우에는 외부 프로그램 이름과 출발 대상을 보여 주며, 실제 도착 폴더와 최종 작업은 외부 프로그램이 결정한다. FxFile 안의 대상처럼 외부 프로그램의 전체 동작까지 통제하거나 보장할 수는 없다. 전원 장애, 저장 장치 오류, 다른 프로그램의 동시 변경, Windows 셸/네트워크 제공자의 실패까지 무조건 복구를 보장하는 기능은 아니다.
