# 7-Zip 기반 기본 내장 압축 관리 시스템 구현 계획

대용량·다량 파일에 대해 업계 최고 수준의 압축률을 자랑하는 7-Zip(LZMA/LZMA2/Deflate)을 기반으로, 압축 파일을 일반 폴더처럼 진입하여 최하위 밑바닥 계층까지 탐색하고 내부에서 추가/복사/이동/삭제를 무손실 원자적(Atomic) 트랜잭션으로 안전하게 수행하는 기본 내장 압축 관리 시스템 구현 계획입니다.

---

## 1. 아키텍처 및 핵심 기술 설계

```mermaid

    B -->|7-Zip LZMA/Deflate 디코더| C[아카이브 내부 가상 디렉터리 트리 파싱]
```

## 2. 세부 구현 컴포넌트

### Component 1: 7-Zip 기반 내장 아카이브 코어 엔진 (`archive_engine.h`, `archive_engine.cpp`)
- **지원 포맷**: `.7z`, `.zip`, `.tar`, `.gz`, `.tgz`, `.bz2`, `.tbz2`, `.xz`, `.txz`, `.rar` (보기), `.iso`, `.cab`, `.wim` 등.
- **아카이브 항목 구조체 (`ArchiveNode`)**:
  - `mVirtualPath`: 아카이브 내 상대 경로 (예: `folder1/sub2/file.txt`).
  - `mIsDirectory`: 디렉터리 여부.
  - `mUncompressedSize`, `mCompressedSize`, `mLastModified`, `mAttributes`.
  - `mChildren`: 중첩 하위 노드 트리맵 (`std::map<std::wstring, ArchiveNode*>`).
- **원자적 크래시 안전 장치 (Atomic Transaction Engine)**:
  - 아카이브 수정 시 원본 파일을 직접 건드리지 않고, 동일 볼륨의 임시 파일(`.tmp_7z_tx_<id>`)에 새 아카이브를 안전하게 패킹.
  - 완료 후 `ReplaceFileW` / `MoveFileExW`로 1ms 내에 원자적 교체하여 정전/프로세스 강제 종료 시에도 원본 훼손 0% 보증.

### Component 2: 가상 아카이브 네비게이션 (`archive_virtual_folder.h`, `archive_virtual_folder.cpp`)
- `ExplorerCtrl` 및 `ExplorerView`와 연동하여 압축 파일 경로(예: `C:\Data\project.7z`) 진입 시 `VirtualArchiveFolder` 모드로 전환.
- **밑바닥 중첩 디렉터리 전수 탐색**:
  - `C:\Data\project.7z` (루트)
  - `C:\Data\project.7z\src` (1차 하위)
  - `C:\Data\project.7z\src\components\parser\deep` (N차 하위 밑바닥)
- `[..]` 클릭 시 상위 가상 디렉터리로 이동하고, 아카이브 루트에서 `[..]` 이동 시 실제 파일시스템 디렉터리로 매끄럽게 탈출 복귀.

### Component 3: 압축 파일 내부 CRUD 조작
- **추가 (Add)**: 외부 파일 또는 다른 탐색창에서 아카이브 뷰포트로 드래그 앤 드롭 / `Ctrl+V` 시 아카이브에 압축 병합.
- **복사 / 추출 (Extract)**: 아카이브 내 항목 선택 후 외부 폴더로 드래그 앤 드롭 / `Ctrl+C` -> `Ctrl+V` 시 즉시 해제 추출.
- **삭제 (Delete)**: 아카이브 내 파일/폴더 선택 후 `Del` 키 누르면 트랜잭션을 통해 아카이브에서 안전 제거.
- **실행 (Open)**: 아카이브 내부 파일 더블클릭 시 임시 캐시 디렉터리로 안전 해제 후 해당 뷰어 또는 기본 프로그램으로 자동 기동.

### Component 4: UI 메뉴 및 툴바 통합
- 메인 메뉴 `파일` 및 컨텍스트 메뉴에 `[7z으로 압축하기]`, `[Zip으로 압축하기]`, `[여기에 압축 풀기]`, `[폴더명으로 압축 풀기]` 커맨드 추가.
- 주소창(AddressBar)에 아카이브 가상 경로 표기 및 히스토리 지원.

## 3. 검증 계획

### 자동화 및 단위/E2E 테스트
1. **아카이브 압축/해제 무결성 테스트**:
   - 다량(1,000+ 개) 및 대용량 파일에 대해 7z 및 Zip 압축/해제 수행 후 SHA256 체크섬 100% 일치 검증.
2. **중첩 하위 디렉터리 깊은 탐색 테스트**:
   - 10단계 이상의 중첩 폴더를 가진 7z 아카이브를 로드하여 최하위 파일까지 정상 렌더링 및 `[..]` 상위 이동 검증.
3. **원자적 수정 안전성 테스트**:
   - 아카이브 내부 파일 추가/삭제 중 강제 취소 시 원본 아카이브 훼손이 전혀 발생하지 않는지 검증.
4. **전체 통합 빌드 및 무결성 감사**:
   - `build_deploy_all.bat`으로 Release x64/x32 빌드 및 3대 대상 배포.
   - `test_e2e_full_system.ps1` 및 `Build-Deploy-Verify.ps1 -Mode VerifyOnly` 100% PASS 확인.
   - 디스크 임시 파일 정리 및 잔여 프로세스 0개 확인.
