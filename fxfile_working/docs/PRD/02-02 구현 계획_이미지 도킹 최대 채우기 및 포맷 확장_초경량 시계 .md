# [Task 065] 이미지 도킹 최대 채우기 및 포맷 확장, 초경량 시스템 시계 및 잠금 기능 신설, 전체 레이아웃 UI 배율(DPI) 조정 시스템 구현 계획서

## 1. 개요 및 목적
사용자의 3가지 새로운 요구사항을 완벽히 충족하기 위한 무결성 보증 상세 리팩토링 계획입니다:
1. **#1. 이미지 도킹 가득 채우기 & 창 크기 연동 리사이징 & 이미지 포맷 확장 (PNG 등)**:
   - 도킹 대상 창의 가용 영역을 최대한 모두 활용하여 가득 채우고(Full fit with aspect ratio), 창 리사이즈 시 동기화.
   - GFL 엔진의 32비트 알파 투명도 지원 및 **GDI+/WIC 하이브리드 코덱 폴백**을 도입하여 PNG, WEBP, TIFF, BMP, ICO, JPG, GIF 등 최신 이미지 포맷 지원 확장.
2. **#2. 초경량 시스템 시계 (연도, 날짜, 시간, 오전/오후) & '시계 위치·크기 잠금' 메뉴 신설**:
   - 시스템 부하가 없는(0% CPU) 실시간 시스템 시계(연도, 날짜, 요일, 오전/오후 시:분:초) 구현.
   - '창 분할·크기 잠금(S)' 메뉴 아래에 **'시계 위치·크기 잠금(S)'** 및 **'시계 표시'** 메뉴 신설 및 상태 보존.
3. **#3. 전체 레이아웃 화면 비율(UI 배율 / DPI 스케일링) 조정 시스템**:
   - 노트북 고해상도 환경에서 메뉴 글자, 레이아웃 아이콘, 파일 목록, 폴더 트리, 탭 글자 등이 작아 보이는 문제를 해결하기 위해 UI 배율(100%, 125%, 150%, 175%, 200%) 동적 스케일링 엔진 구축.
   - 기본값은 현재 100% 기준 유지.

## 2. 사용자 검토 및 확인 필요 사항 (User Review Required)

> [!IMPORTANT]
> - **이미지 도킹 모드 레이아웃**:
>   - 도킹 대상 창(`ExplorerView`)에서 폴더 트리가 있는 경우 폴더 트리 하단 전체 영역을 넓게 점유하고, 폴더 트리가 없거나 전용 뷰일 경우 해당 창의 전체 뷰포트를 가득 채워(Full fill) 렌더링합니다.
> - **시계 표시 위치**:
>   - 상태 표시줄(Status Bar) 우측 전용 패널에 실시간으로 표시되며, 원할 경우 독립된 경량 시계 창으로 띄우거나 '시계 위치·크기 잠금'으로 안전하게 고정할 수 있습니다.
> - **UI 배율 스케일링**:
>   - 보기 메뉴 및 옵션에 `100% (기본)`, `125%`, `150%`, `175%`, `200%` 항목이 제공되며 선택 즉시 전체 글꼴 크기와 행 높이가 스케일링됩니다.
