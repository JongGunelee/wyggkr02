### 2단계: archive_engine.cpp 전면 재작성 (실제 7z.exe CLI 기반)

#### [MODIFY] [archive_engine.cpp](file:///c:/Users/PC/Downloads/0000%20FxFile/fxfile_working/src/fxfile/archive_engine.cpp)

- **`find7zExePath()`**: 시스템에서 `7z.exe` 경로를 자동 탐지 (레지스트리 → Program Files → PATH)
- **`createArchive()`**: `7z.exe a -t7z -mx=9 "archive.7z" "files..."` 실행 → 실제 .7z 포맷 생성
- **`extractAll()`**: `7z.exe x "archive.7z" -o"dest" -y` 실행 → 실제 7z 엔진 해제
- **`listArchive()`**: `7z.exe l -slt "archive.7z"` 실행 → 아카이브 내부 파일 목록 파싱
- **`executeProcessWithProgress()`**: 자식 프로세스의 stdout을 파이프로 읽어 `-bsp1` 출력에서 진행률 % 파싱 → 프로그레스 바 콜백 호출
- tar.exe/PowerShell 폴백은 7z.exe 미설치 시에만 사용
