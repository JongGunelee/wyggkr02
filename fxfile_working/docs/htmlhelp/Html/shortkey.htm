마우스 오른쪽 버튼선택 항목 또는 FxFile의 상황별 메뉴 표시

4. 단축키 사용자 정의

[도구 → 단축키 설정]에서 명령별 단축키를 추가·제거하거나 기본값으로 복원할 수 있습니다. 동일한 키 조합을 다른 명령에 지정하면 기존 명령의 조합은 제거되고 새 명령 하나에만 지정됩니다. 사용자 설정 파일이 손상되면 프로그램은 안전하게 기본 단축키로 복귀합니다.
